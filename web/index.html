THE INFRASTRUCTURE OF TRUST.

Modern technology is judged not only by what it can do, but by how it handles data and user control. WALE aims for a system with clear principles on data, access, and operational responsibility.

1
DATA TRANSPARENCY
Information about data collection and use should be stated clearly. WALE runs locally and transmits no data — so there is nothing to hide.
2
ACCESS CONTROL
Access should match role and purpose. The entire system lives on your machine; access begins and ends there.
3
SECURITY BY DESIGN
Security should be considered during design, not added after the system is finished. There is no central server, so there is no centralized attack surface.
4
USER AGENCY
Users should have the information needed to understand and manage their relationship with the platform. Learned data can be deleted at any time — and the deletion is in your hands.

Trust is not a feature. It is an architecture.

09 / FAQ

FREQUENTLY ASKED QUESTIONS

ASK TO UNDERSTAND, NOT TO BELIEVE
What is WALE?

WALE is a technology project building a probabilistic language-generation system that runs locally and depends on no centralized infrastructure. It is the starting point of an ecosystem, not a finished product.

Who is WALE built for?

For people who want a tool they truly understand and control — running on their own machine, sending no data anywhere, depending on no API that can change price or shut down at any moment.

Is WALE free?

The current — and only — plan is free, forever. Open-source model. The paid plans in the pricing table are a direction for the future, not yet deployed.

Can WALE scale?

Real scalability depends on architecture, infrastructure, and testing. A development direction does not replace measured performance. The current architecture is designed to allow components to be added, but that must be proven by testing, not by claims.

Who is behind WALE?

One person: Jmy. No board, no advisory council, no funding rounds. That is both a strength and a real limitation of the project at this point.

Is WALE related to ghost hunting?

Only in one respect: the founder has a personal interest in how people interpret phenomena they don't fully understand — the gap between the data collected and the conclusion drawn. It is a personal perspective, an inspiration for how WALE is built, not the subject of the project.
